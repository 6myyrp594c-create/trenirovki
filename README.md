# Трекер тренировок

Локальное веб-приложение для телефона. Данные хранятся в браузере. У каждой тренировки запоминается прошлый вес и повторы.

## Открыть на айфоне

1. Компьютер и айфон должны быть в одной сети Wi-Fi.
2. Запустите `Запуск.bat`.
3. В окне появится адрес вида `http://192.168.x.x:8080`. Откройте его в Safari.
4. Нажмите «Поделиться» → «На экран Домой».

Если Windows спросит разрешение брандмауэра, разрешите доступ в частной сети.

На этом компьютере приложение открывается по адресу http://localhost:8080.

## Что умеет

- Тренировки с упражнениями и несколькими подходами: вес, повторы, отдых.
- При открытии тренировки виден вес с прошлого раза, его можно изменить.
- Запись тренировки попадает в историю. В течение 6 часов повторное сохранение обновляет сегодняшнюю запись, а не создаёт дубль.
- Таймер отдыха и таймер длительности упражнения. По окончании — звук.
- Экспорт и импорт файла JSON в разделе «Данные».

## Позже на GitHub Pages

Загрузите файлы проекта в репозиторий и включите Pages из ветки `main`, папка root. Откройте выданный адрес `https://…github.io/…` на айфоне и добавьте его на экран «Домой». Сервер не нужен: это статический сайт.
